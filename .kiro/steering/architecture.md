# AgentGate Steering & Design Standards

## Architectural Principles
1. **Deterministic Token Compression:** Every web target must be compiled into a structured schema (`META`, `DATA_BLOCKS`, `INPUT_CONTROLS`, `ACTION_TRIGGERS`, `HIDDEN_JSON_PIPES`) with exact pre- and post-compilation token telemetry.
2. **Human-Engineered Interface:** Strictly adhere to high-density developer tooling aesthetics (`#0D1117` obsidian canvas, `#161B22` surfaces, `#21262D` 1px borders, `#10B981` emerald status indicators, monospace telemetry). No emojis or decorative gradients.
3. **Safety-First Execution:** Financial and destructive triggers must be classified at compile time and gated when `safetyBrake` is enabled.
